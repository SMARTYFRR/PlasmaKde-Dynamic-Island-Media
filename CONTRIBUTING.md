# Contributing

Thanks for your interest in improving Dynamic Island Media! 🎉

## Getting started

1. Fork and clone the repo.
2. Make your changes under `package/`.
3. Install and test:
   ```bash
   ./install.sh
   ```
   For fast iteration, test in a standalone window using:
   ```bash
   plasmawindowed com.anshatetheapples.dynamicisland.media
   ```

## Guidelines

- **Pure QML** — no build step required.
- **Minimalist & Lightweight** — keep idle CPU overhead at zero.
- Update `CHANGELOG.md` and bump the version in `package/metadata.json`.
