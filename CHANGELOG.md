# Changelog

All notable changes to this project are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] - 2026-08-19
### Added
- Created **Dynamic Island Media**, a standalone, ultra-lightweight KDE Plasma 6 widget dedicated to media playback & audio visualizer.
- Custom `SoundBars` audio visualizer animation for MPRIS players.
- Album art & track title display in compact capsule.
- Mouse wheel volume & track skipping controls.

### Removed
- Removed expanded popup dialog view for a clean, non-intrusive panel capsule.
- Stripped background system sensors, clock timers, notification listeners, FPS meters, and IDE build listeners for zero idle CPU overhead.
- Removed unused configuration pages.
